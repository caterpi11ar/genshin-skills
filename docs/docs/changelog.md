# 更新日志

这里记录会影响使用者、部署者或贡献者的实质变化。每次合并新增功能、行为调整、兼容性变化、依赖升级、安全修复或能力状态变化时，都应先在“待发布”下增加一条简洁说明；发布新版本时，再将这些条目移动到对应版本和日期下。

不需要记录纯格式调整、本地运行数据、临时调试过程，以及不改变外部行为的内部重构。

## 待发布

### 新增

- 新增更新日志页面，并接入文档站导航、README 和贡献指南。
- 新增 GitHub PR 检查清单，在每次合并请求中提醒维护更新日志、关联文档、验证结果和敏感文件边界。

### 调整

- 文档聚焦 giclaw 自身能力、真实验收状态和项目路线，不再展示第三方项目对比内容。

## 0.3.0 — 2026-08-07

### 新增

- 新增 10 个视觉 AI 操作与 12 个确定性键鼠/诊断操作，工作流可以混合使用两类步骤。
- 新增任务依赖展开、去重、依赖环检测，以及 `daily`、`rewards`、`full` 命名流程。
- 新增成就奖励和活动奖励任务；补齐纪行与探索派遣的可执行步骤定义。
- 新增仅支持流式响应的 OpenAI 兼容服务适配：继续调用 Chat Completions，并在项目内聚合 SSE 分片。
- 新增任务加载、依赖编排、队列上限、Gateway 目录和流式客户端自动化测试。

### 调整

- `@midscene/web` 升级至 `1.10.9`，未接入 Responses API。
- Cookie 恢复检查改为最多等待 15 秒；无有效 Cookie 时自动打开可见浏览器引导登录。
- 优先使用 Playwright Chromium，不可用时复用系统 Chrome、Edge 或 Chromium。
- 默认任务保持月卡与邮件；推荐通过 `rewards` 运行全部 5 个已验收奖励任务。
- 全面同步 README、文档站首页、模型配置、CLI 和能力状态说明。

### 修复

- 空步骤、未知任务、未知操作、错误 ID 和无效依赖不再被静默当作成功。
- 修复模型家族传递、任务超时与重试、队列深度以及失败依赖仍继续执行的问题。
- 失败步骤会保存现场截图并写入 transcript，便于定位真实环境问题。

### 真实环境状态

- 已通过：月卡、邮件、纪行、成就和活动奖励。
- 已暂停：探索派遣；尚未完成领取与再次派遣闭环，不包含在推荐的 `rewards` 流程中。

## 维护规则

推荐使用以下分类，按用户能够理解的结果描述变化：

- **新增**：新增功能、任务、命令或配置。
- **调整**：已有行为、默认值、依赖或兼容性发生变化。
- **修复**：修复了可以被用户观察到的问题。
- **弃用 / 移除**：能力即将停止支持或已经删除。
- **安全**：权限、凭据、隐私或高风险操作相关修复。

每条记录应说明“发生了什么”和“对用户有什么影响”，避免只写提交号、文件名或调试过程。
