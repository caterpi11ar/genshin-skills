# 内置技能详情

所有内置技能按依赖展开后的顺序在同一浏览器会话中执行。截至 2026-08-07，月卡、邮件、纪行、成就和活动奖励均已在真实账号环境完成全流程验收，并且默认全部启用；探索派遣保持关闭和暂停状态。

| 技能 | 默认状态 | 真实账号验收 |
|---|---|---|
| `welkin-moon` | 启用 | 已通过 |
| `claim-mail` | 启用 | 已通过 |
| `battle-pass-claim` | 启用 | 已通过 |
| `claim-achievements` | 启用 | 已通过 |
| `claim-event-rewards` | 启用 | 已通过 |
| `expedition-collect` | 关闭 | 暂停，未完成领取与再次派遣闭环 |

## welkin-moon — 月卡每日领取

- **ID**: `welkin-moon`
- **说明**: 登录 → 启动游戏 → 领取月卡奖励
- **超时**: 10 分钟（`600000ms`）
- **重试**: 1 次
- **验收**: 真实账号全流程已通过

### 执行顺序

**必须排在第一个。** 此技能负责打开云原神页面、完成登录流程、启动游戏。后续所有技能都依赖它建立的游戏内会话。

### 前置条件

- 账号可以正常进入云游戏平台；没有有效 Cookie 时程序会自动打开可见浏览器引导登录
- 已购买月卡时会领取当日奖励；没有奖励弹窗时继续完成游戏启动流程

### 已知限制

- 云原神可能出现排队等待，技能会自动等待排队完成
- 启动后可能弹出新手引导、用户协议等弹窗，技能会尝试关闭
- 如果游戏画面长时间无响应（如 canvas 未激活），可能需要点击激活
- 网络波动可能导致启动超时，建议在网络稳定时运行

## claim-mail — 邮件领取

- **ID**: `claim-mail`
- **说明**: 打开邮箱 → 一键领取所有附件
- **超时**: 5 分钟（`300000ms`）
- **重试**: 1 次
- **验收**: 真实账号全流程已通过

### 执行顺序

声明了 `dependsOn: [welkin-moon]`，即使单独选择也会自动先启动游戏。

### 前置条件

- 游戏已启动并进入主界面（由 `welkin-moon` 完成）

### 已知限制

- 工作流会打开邮箱并检查底部“全部领取”按钮；按钮为灰色或邮件列表为空时不执行领取
- 领取附件后可能弹出物品展示弹窗，技能会自动关闭
- 如果误入其他界面，工作流会退出后重新确认主界面状态

## expedition-collect — 探索派遣收取（暂停）

- **ID**: `expedition-collect`
- **说明**: 收取已完成派遣并重新派遣
- **超时**: 10 分钟（`600000ms`）
- **重试**: 1 次
- **默认**: 关闭
- **验收**: 暂停，尚未完成领取与再次派遣闭环

### 执行顺序

声明了 `dependsOn: [welkin-moon]`。能力定义暂时保留，但当前不在稳定回归集合中，也不包含在推荐的 `rewards` 流程中。

### 前置条件

- 游戏已启动并进入主界面

### 当前结论

暂不运行或继续调试该能力。需要稳定奖励领取时使用 `rewards`，不要使用仍包含本能力的默认 `full` 流程。

## battle-pass-claim — 纪行奖励领取

- **ID**: `battle-pass-claim`
- **说明**: 打开纪行 → 领取可领取的等级奖励
- **超时**: 5 分钟（`300000ms`）
- **重试**: 1 次
- **默认**: 启用
- **验收**: 真实账号全流程已通过

### 执行顺序

声明了 `dependsOn: [welkin-moon]`，运行时会自动先启动游戏。

### 前置条件

- 游戏已启动并进入主界面

### 已知限制

- 当前工作流从游戏菜单进入纪行，并在 1280×720 视口使用已验收的固定入口坐标
- 纪行界面有多个标签页（纪行任务、纪行之证等），需要确保在奖励领取页面
- 只领取已解锁（亮起）的奖励，灰色未解锁的会跳过
- 版本更新后纪行可能重置，界面布局可能变化
- 领取奖励后的物品展示弹窗需要关闭

## claim-achievements — 成就奖励领取

- **ID**: `claim-achievements`
- **说明**: 打开成就 → 遍历带红点分类 → 领取已完成成就
- **默认**: 启用
- **依赖**: `welkin-moon`
- **验收**: 真实账号全流程已通过

只处理明确带红点且可领取的成就，不改变展示设置。

---

## claim-event-rewards — 活动奖励领取

- **ID**: `claim-event-rewards`
- **说明**: 打开活动总览 → 领取明确已解锁的奖励
- **默认**: 启用
- **依赖**: `welkin-moon`
- **验收**: 真实账号全流程已通过

活动 UI 版本变化频繁。工作流只点击明确可领取的已解锁奖励，并明确禁止购买、消耗原石和进入挑战。版本更新后首次回归仍建议使用可见模式观察。
